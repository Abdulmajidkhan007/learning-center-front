# Uch tillilik (uz / ru / en)

Interfeys uch tilda: **o'zbekcha (lotin)**, **ruscha**, **inglizcha**.
Sukut bo'yicha — o'zbekcha.

## Qanday ishlatiladi

```tsx
import { useT } from '@/shared/i18n'

function Example() {
    const { t } = useT()
    return <h1>{t('teacher.studentsCount', { count: 12 })}</h1>
}
```

Til `localStorage` dagi `clc-locale` kalitida saqlanadi. Almashtirish ikki
joyda: **Sozlamalar → Ko'rinish** va **kirish sahifasi** (foydalanuvchi hali
tizimga kirmagan bo'lsa ham tilni tanlay olishi kerak).

## Nega tayyor kutubxona emas

`i18next` — kuchli, lekin bizga kerak bo'lgani: kalit → matn, `{{name}}`
almashtirish va til tanlash. Bularning hammasi ~40 qator kod
(`shared/i18n/translate.ts`). Buning evaziga **kalitlar to'liq tiplangan**:
mavjud bo'lmagan kalitni yozsangiz kod kompilyatsiya bo'lmaydi, i18next'da
esa buning uchun qo'shimcha sozlash kerak bo'lardi.

Murakkabroq narsa kerak bo'lsa (masalan sonli kelishik qoidalari yoki
sana formatlari) — o'shanda kutubxonaga o'tish mumkin, `useT` interfeysi
o'zgarmaydi.

## Yangi matn qo'shish

1. `src/shared/i18n/locales/uz.ts` ga kalit va o'zbekcha matn qo'shing.
   **Bu fayl haqiqat manbai** — kalitlar tipi shundan chiqadi.
2. `ru.ts` va `en.ts` ga o'sha kalitni qo'shing. Unutsangiz — `npm run
   typecheck` xato beradi, chunki ular `Translations` tipiga bo'ysunadi.
3. Komponentda `t('yangi.kalit')`.

Kalit nomlash: `soha.narsa` (`admin.records`, `teacher.startLesson`).
Umumiy tugmalar — `common.*`.

## Testlar

`src/shared/i18n/locales/locales.test.ts` uchta narsani tekshiradi:

- kalitlar to'plami uch tilda **bir xil** (ortiqcha kalitni ham ushlaydi —
  buni tip tizimi ko'rmaydi);
- hech bir matn bo'sh emas;
- **o'rin egallovchilar mos** — `{{count}}` bir tilda bo'lib, boshqasida
  unutilsa, ekranda buzuq matn chiqadi. Test buni oldindan ushlaydi.

## Ma'lum cheklov: rus tilidagi son kelishigi

Rus tilida son bilan ot kelishigi o'zgaradi (1 ученик / 2 ученика /
5 учеников). Bizning `translate` bu qoidani bilmaydi.

Yechim sifatida ruscha matnlar ataylab **kelishik talab qilmaydigan**
shaklda yozilgan: "Ученики: 5", "Прошедших занятий: 5". Bu har qanday son
bilan to'g'ri o'qiladi.

Agar kelajakda haqiqiy plural kerak bo'lsa — `Intl.PluralRules` qo'shiladi,
lug'atlarda esa o'sha kalitlar uchun uchta variant saqlanadi.

## Nima tarjima QILINMAYDI

- **Backenddan keladigan ma'lumot** — guruh nomi, o'quvchi ismi, xato
  xabarlari. Ular serverda qanday bo'lsa, shunday ko'rsatiladi.
- **Sana va vaqt** — hozircha backend formatida (`yyyy-MM-dd`, `HH:mm`).
  Tilga qarab formatlash kerak bo'lsa, `Intl.DateTimeFormat` bilan
  `shared/lib/format.ts` da qilinadi.
